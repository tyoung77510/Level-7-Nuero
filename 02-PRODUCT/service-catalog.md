## The Foundation Audit — $7,500 (2 weeks)
**Our flagship assessment.** Fast, direct, actionable. ~70% convert to implementation.

### Deliverables
| Item | Description |
|------|-------------|
| Executive Report (5 pages) | Leadership summary with key findings, risk ratings, recommendations |
| Technical Appendix (20+ pages) | Detailed findings with data, process maps, evidence |
| Implementation Roadmap | Phased plan with estimated costs, timelines, ROI |
| 30-Minute Results Briefing | Presentation and Q&A with decision-makers |

### Four Domains Assessed
| Domain | What We Evaluate |
|--------|-----------------|
| Project Management | Methodology maturity, governance, team capability |
| Project Controls | Cost tracking, schedule reliability, EVM readiness |
| CMMS & Maintenance | System evaluation, data quality, asset management maturity |
| Data & Process | Data cleanliness, process documentation, workflow efficiency |

### Conversion Funnel
```
Foundation Audit → Roadmap → Implementation Proposal → Signed Engagement
     70% convert     90% accept        60% accept         Avg $75K+
```

## Clean Sheet — $20,000 (4–8 weeks)
**Tagline:** *"Scrub the data. Fix the flow."*

### What's Included
- Data quality audit and scoring (completeness, accuracy, consistency, timeliness)
- Data cleansing and standardization (assets, parts, vendors, locations)
- Process mapping — current state (BPMN, VSM)
- Bottleneck and waste analysis (TIMWOODS)
- Future state process design
- SOP development (up to 20 SOPs)
- Documentation system setup
- Team training on new processes

### Who Needs This
- Companies with messy, inconsistent data
- Undocumented processes
- Firms preparing for ERP/CMMS implementation
- High turnover and tribal knowledge loss

## Project Velocity — $25,000 (6–12 weeks)
**Tagline:** *"Stop firefighting. Start delivering."*

### What's Included
- PMO maturity assessment and design (Level 1–5 model)
- Methodology selection and implementation (Waterfall/Agile/Hybrid)
- Governance framework (stage gates, steering committees, escalation)
- Project charter and business case templates
- Stakeholder management plan
- Risk management framework
- Team training and coaching (up to 20 people)
- 30-day post-implementation support

### Who Needs This
- Companies with no formal PMO
- Spreadsheet-based project tracking
- Engineering firms with repeated project overruns
- Teams that have "tried Agile" and failed

---

## Control Tower — $30,000 (8–12 weeks)
**Tagline:** *"See everything. Control everything."*

### What's Included
- EVM system design and implementation (ANSI/EIA-748 compliant)
- Cost baseline development and management
- Schedule baseline and critical path analysis
- KPI dashboard design (executive + operational views)
- Variance analysis and reporting framework
- Change control system
- Forecasting models (EAC, TCPI)
- Team training on EVM fundamentals

### Who Needs This
- Cost overruns on every project
- No real-time project visibility
- Fixed-price contracts with poor cost control
- Preparing for government/defense contracts

## Asset Integrity — $35,000 (8–16 weeks)
**Tagline:** *"Make your equipment last."*

### What's Included
- CMMS platform evaluation and selection support
- Asset hierarchy and criticality analysis
- Preventive maintenance program design
- Data migration and data cleanup
- System configuration and setup
- User training and adoption support
- KPI framework (MTBF, MTTR, OEE)
- 60-day post-implementation support

### Who Needs This
- Outdated or unused CMMS

- Preparing for digital transformation

## Pricing Philosophy
- **Value-based, not time-based.** We price on the value delivered, not hours spent.
- **Fixed fee.** No hourly billing surprises. Clients know the cost before we start.
- **5x–10x ROI typical.** If we can't show the math before we start, we don't start.
- **Milestone payments** on implementation projects.
