# Level 7 Consulting — Digital Brain

**Bringing order to operational chaos.**

This repository is the versioned knowledge base for Level 7 Consulting — a specialized consulting agency for mid-market ($20M–$500M) industrial and engineering firms. It's the source of truth for strategy, service packages, delivery methodology, sales/marketing, client management, brand, and infrastructure — structured so any team member (human or AI) can find what they need without asking anyone.

## Structure

The brain is organized into 7 numbered sections, each with a Map of Content (MOC) index:

| # | Section | Covers |
|---|---------|--------|
| 01 | `01-STRATEGY/` | Business plan, competitive positioning |
| 02 | `02-PRODUCT/` | Service catalog — 7 packages, $7.5K–$150K+ |
| 03 | `03-DELIVERY/` | PMO frameworks, EVM/controls, CMMS/data, quality standards, engagement lifecycle |
| 04 | `04-SALES-MARKETING/` | Outreach playbook, target clients, LinkedIn strategy, sales materials |
| 05 | `05-CLIENT/` | Onboarding, relationship management, quick wins |
| 06 | `06-BRAND/` | Brand identity, visual assets |
| 07 | `07-INFRASTRUCTURE/` | Tech stack, team roles, directory structure |

Notes link to each other with `[[wikilinks]]` (Obsidian-compatible). `00-MOC-MASTER.md` is the single navigation hub — start there for the full map.

## How We Build

Every system, SOP, or tool in this brain is built using the Musk Algorithm: question the requirement → delete the part → simplify → accelerate → automate, in that order. See [`SOUL.md`](./SOUL.md) for the full method.

## Note on Scope

This repo versions the Digital Brain only. Client work, SOPs, and visual assets live on the team's shared filesystem (`/home/team/shared/`) — see [`07-INFRASTRUCTURE/directory-structure.md`](./07-INFRASTRUCTURE/directory-structure.md). Changes made directly on the shared filesystem should be synced back here to keep this repo authoritative.
