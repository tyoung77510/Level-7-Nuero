# Engagement Lifecycle — The 5-Phase Delivery Model
> **Source:** SOP-002 (Engagement Lifecycle) | **Last Updated:** 2026-07-11

## Overview
```
Discovery → Assessment → Design → Implement → Support
```

## Phase 1: Discovery (Weeks 1–2)
**Lead:** Project Management Agent
- Stakeholder interviews (executive, operations, IT, maintenance)
- Systems inventory and documentation review
- Process walkthroughs
- Pain point identification and prioritization
- **Output:** Current State Assessment + Discovery Findings Report

## Phase 2: Assessment (Weeks 1–3)
**Lead:** Varies by scope (PM / Controls / Data Agent)
- Deep-dive analysis into specific problem areas
- Data quality audit (data/CMMS engagements)
- Project portfolio review (PM engagements)
- Control system evaluation (controls engagements)
- Maturity benchmarking
- **Output:** Assessment Report with Gap Analysis

## Phase 3: Design (Weeks 2–4)
**Lead:** Relevant delivery agent + Team Lead
- Solution architecture
- Implementation roadmap
- Resource requirements
- Risk assessment
- Success metrics definition
- **Output:** Implementation Plan + Solution Design Document

## Phase 4: Implement (Weeks 4–16)
**Lead:** Full delivery team
- System deployment / process rollout
- Data migration / cleanup execution
- Controls setup and baseline establishment
- Training and capability transfer
- Regular status reporting
- **Output:** Deployed solution + Training Materials + As-Built Documentation

## Phase 5: Support (Ongoing)
**Lead:** Assigned support agent
- Hyper-care (first 2 weeks post-implementation)
- Monthly/quarterly reviews
- Continuous improvement recommendations
- Ad-hoc troubleshooting
- **Output:** Monthly Status Reports + Quarterly Business Reviews

## Quality Gates
| Gate | Criteria | Reviewer |
|:----:|----------|----------|
| G1 | Client confirms findings are accurate | Client sponsor |
| G2 | Design meets all requirements from assessment | Team Lead |
| G3 | Implementation plan sign-off from all stakeholders | Team Lead + Client |
| G4 | Solution passes acceptance testing | Client QA team |
| G5 | Support transition complete with documentation | Team Lead |
