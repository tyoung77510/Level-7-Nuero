# Competitive Positioning
> **Source:** System prompt, branded-service-packages.md, services.md, outreach-templates.md | **Last Updated:** 2026-07-11

## Market Position
Level 7 Consulting sits in a specific, underserved niche:
- **Not** the Big 4 (Deloitte, Accenture, McKinsey) — those are too expensive and generic for $20M–$500M firms
- **Not** freelancers — we have a full team with documented methodology covering all four pillars
- **Not** pure software resellers — we're methodology-first, tool-agnostic
- **Not** ERP implementers — we fix the operations *around* the systems

## The Four Pillars — Our Unique Differentiator
Most consulting firms specialize in ONE area. We deliver all four, and they're interconnected by design:

```
┌─────────────┐     ┌─────────────┐
│   Project   │ ◄──►│   Project   │
│ Management  │     │  Controls   │
└──────┬──────┘     └──────┬──────┘
       │                   │
       │   ┌───────────┐   │
       └──►│   Data &  │◄──┘
           │  Process  │
       ┌──►│   (CMMS)  │◄──┐
       │   └───────────┘   │
┌──────┴──────┐     ┌──────┴──────┐
│ Operational │     │   Client    │
│  Efficiency │     │  Outcomes   │
└─────────────┘     └─────────────┘
```

Fix PM without Controls → you manage chaos more efficiently. Fix CMMS without Data → the system is empty. Fix Data without Process → the data rots again. We fix them together.

## Our Differentiators in Client Language
1. **"We're not too big to care about you."** — Mid-market focus means mid-market attention
2. **"We tell you the hard truth in 14 days."** — The Foundation Audit is fast, direct, and actionable
3. **"Fixed price. No surprises."** — Clients hate hourly billing uncertainty
4. **"Your team runs it when we leave."** — Capability transfer is built into every engagement
5. **"We fix all four legs of the stool."** — Integrated approach across PM, Controls, CMMS, Data

## Target Buyer Personas

### "Stretched Steve" — COO / VP Operations
- Managing growth chaos
- 5 plants, 3 different systems, no standard processes
- Knows something needs to change but can't stop firefighting long enough to fix it
- **Hook:** "What's your operational chaos budget?"

### "Paper Paul" — Plant Manager
- Data in spreadsheets, PMs on whiteboards, parts in chaos
- Maintenance team is reactive; every day is a fire drill
- **Hook:** "How many hours of unplanned downtime last month?"

### "Project Pete" — Engineering Manager
- Projects consistently over budget and behind schedule
- No EVM, no visibility, reporting is a fiction
- **Hook:** "When was the last time you trusted a project status report?"
