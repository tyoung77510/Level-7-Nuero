# GTM action log — relationship-building engine

> **Status:** ✅ Active | **Purpose:** Source of truth for the daily GTM outreach Routine — what's been researched, what's been drafted, what's waiting on Taj to review and send. | **Last Updated:** 2026-07-22

Companion to `founder-log-calendar.md`'s "GTM action items" checklist. That doc says *what* the near-term moves are; this log tracks *actual daily progress* on the relationship-building ones specifically (earned-coverage outreach, the referral/consultant channel, event presence) — the categories that involve reaching a real person or organization, as opposed to the SEO blog backlog, which is content work tracked through the normal Founder Log/blog pipeline instead.

## Hard rules for the Routine

- **Never fabricate a target.** Every person, publication, community, consultant, or event named below must be real and found via an actual search that day — cite the source. If nothing real turns up in a category on a given day, say so and move to the next category; don't invent a placeholder to fill the log.
- **Never send anything.** The Gmail connection only supports creating drafts — there is no send capability, by design. Every drafted email sits in Gmail as a draft for Taj to review, personalize further if needed, and send himself.
- **Personalize, don't template.** Each draft should reference something specific and real about the recipient (their actual content, their actual community, their actual event) — a generic blast defeats the point of this channel. If there isn't enough real information to personalize genuinely, do more research before drafting, or skip drafting and just log the target for later.
- **Flag judgment calls, don't resolve them.** If a target is ambiguous, a poor fit, or requires a decision only Taj can make, log it as a question rather than guessing.

## The 3-category rotation

Each weekday, the Routine works one category (`(day count − 1) mod 3`), so all three get steady, even attention rather than one dominating:

1. **Earned-coverage outreach** — PM/scheduling educators, niche communities (Planning Planet, PMI local chapters), construction-scheduling YouTube/newsletter voices, trade outlets. Goal: find one real, specific target per turn and draft a genuine pitch or guest-content ask.
2. **Referral/consultant channel** — independent project-controls consultants, freelance schedulers, Primavera trainers who might refer clients. Apollo.io is now live on a Basic plan (as of 2026-07-21) — check whether it's enabled in the current session before falling back to web search only. A vetted, hand-reviewed list of 704 real ICP-matched companies is now available in the private `ordo7-competitive-intel` repo at `gtm-target-list/ordo7-gtm-target-list.csv` (see that folder's README for sourcing/methodology and what was excluded/flagged) — this and event presence (below) are the two categories it's actually useful for; earned-coverage outreach still needs individual educators/consultants, not companies. Pick the next unused company from that list matching this category, then still do the same real verification/personalization pass before drafting — the list shortcuts "find a plausible company," not "verify and personalize."
3. **Event presence** — regional/local AGC chapter events, startup/tech-showcase tracks at larger construction-tech conferences. Goal: find a real, dated, upcoming event and either identify how to apply/attend, or draft an inquiry email to the organizer. The same target-list CSV above can also surface companies worth inviting to / connecting with around an event, once a specific event is identified.
